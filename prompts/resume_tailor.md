# Resume Tailoring Prompt

You are helping tailor a resume for a specific job application.

Use only the provided career profile and source evidence. Do not invent credentials, employment, metrics, tools, or responsibilities.

## Inputs

- Career profile
- Job posting
- Current base resume, if provided

## Output

Return:

1. Targeting strategy
2. Customized resume draft
3. Evidence map for each major claim
4. Keyword alignment notes
5. Gaps and risks
6. Human verification checklist

## Style

- Clear, direct, and credible
- Product and program leadership language
- Strong outcome orientation
- No exaggerated seniority
- No unexplained acronyms
